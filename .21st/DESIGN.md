# Pi Bot design context

Warm cream and coral messenger using React and Radix Themes. The approved asymmetric pi logo is reused unchanged. The current palette and component refinements live in src/gui/brand.css. Reuse mature Radix controls. Keep the chat composer simple; provide @ suggestions and @全体成员. Every group member sees public messages. Keep direct bot conversations distinct. Schedules and monitors belong to each bot; their details are read-only. Settings use a vertical category navigation and compact named runtime connection rows. Add saves a profile; Connect connects it. Connection state stays beside the chat/list title in a low, soft rounded rectangle with side clearance. Its settings target remains 44px tall; first setup offers compact in-shell local/remote choices on supported desktops and a Settings entry on phones. Returning connections restore once; errors lead to Settings without a full-width strip, repeated explanation or recovery hero. Built-in harness is a protected connection row, distinct from an independently installed local service. Computer operation, browser operation and screen viewing use the harness capability report; inspecting the panel never starts a viewer. Show Local/Cloud only with multiple profiles. Keep advanced paths out of the primary flow. Runtime data and Pi authentication stay independent. Model settings are the primary page; authentication is a secondary page behind Manage authentication, not a peer tab. Keep provider auth selection independent of model selection and put search inside model/provider pickers. Avatar editing uses original SVG shapes, color swatches and raster uploads. Preserve existing bots and real messages; never synthesize demonstration replies. Do not use Ant Design. See design.json and gui/style.css.

Scheduling and file monitors are agent-owned. Client details and search expose existing status read-only; no manual creation, time/interval forms, or lifecycle controls. Details dialogs use one Radix ScrollArea with a subtle overlay scrollbar, modal background lock and keyboard focus restoration.

# Pi Bot design context

Dark, compact local messenger using React and Radix Themes. Reuse mature Radix controls. Keep the chat composer simple; provide @ suggestions and @全体成员. Every group member sees public messages. Keep direct bot conversations distinct. Schedules and monitors belong to each bot and are managed in its details. Settings use a vertical category navigation and named runtime cards. Add saves a profile; Enable connects it. Show Local/Cloud only with multiple profiles. Keep advanced paths out of the primary flow. Runtime data and Pi authentication stay independent. Model settings are the primary page; authentication is a secondary page behind Manage authentication, not a peer tab. Keep provider auth selection independent of model selection and put search inside model/provider pickers. Avatar editing uses original SVG shapes, color swatches and raster uploads. Preserve existing bots and real messages; never synthesize demonstration replies. Do not use Ant Design. See design.json and gui/style.css.

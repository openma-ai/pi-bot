## Conversation pins and atomic replies

The prior fixture list had no pinned state; shared pin support already existed. Real iPhone long-press exposed an additional defect: iOS text selection/copy UI covered the pin menu. Navigation-only user selection is now disabled; message copying is unchanged. A descendant avatar size selector also enlarged group members over their tile label; it now applies only to the direct single-bot avatar, with an explicit group tile size.

Accepted evidence in `artifacts/ios-evidence/iphone17-atomic-pins/`:

- `two-pins-persisted.png`: a pinned bot and group after process restart/reinstall; centered tiles, readable labels and visible pinned heading. Library `libfile_19740466144481919a42234a5ac0393d`.
- `unpin-menu.png` / `after-unpin.png`: real long-press and unpin return the bot to the ordinary list while leaving the group pinned.
- `pinned-group-open.png`: opens the real fixture group from its tile; returning retains pins.
- `running-no-partial.png`: the bot's lifecycle reports Running while delta events arrive, with no partial assistant bubble. Library `libfile_1da1ac58c03081919985a875b9c69cc0`.
- `atomic-complete-reply.png`: one full response replaces the waiting state, with prior complete history preserved. Library `libfile_3fa33538d19c8191bcb466ea9d732a95`.

Pins remain in the existing per-runtime local-storage map. Desktop right-click and keyboard context-menu support remain intact. There is no forced default pin and no migration of another runtime's pins.

Desktop and iOS use the same completed-message projection. Delta buffers remain internal to the SDK; they never become message bubbles. Running comes from bot-owned turns/jobs and remains separate from pending human requests. Four focused tests cover multiple senders, completion deduplication, snapshot/reconnect reconciliation, completed history, failure/cancellation cleanup, unrelated bots and concurrent work alongside pending decisions. Together with presentation/layout/identity/profile checks, 28 tests passed. GUI lint and TypeScript passed; native fixture suite passed 8 tests with `PIBOT_SSH_FIXTURE_ROOT` set.

The temporary coordinate/XCTest event harness is preserved under evidence only, not shipped in the application project. Runs with empty fixtures or blank WebViews were rejected even when XCTest reported success. The host must explicitly install the latest built app before direct launch; building the unused test host target alone did not reliably replace the installed app.
